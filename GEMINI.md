# User Preference Rules for Antigravity AI

## Interactive Approval Mode (તમારો વિચાર જણાવીને YES/NO ની રાહ જુઓ)

- **Do NOT execute commands or make code edits immediately after a user question/request.**
- Whenever the user asks a question or gives a task/instruction:
  1. First, analyze the task and share your proposed approach, plan, or ideas in plain text.
  2. Clearly present your thoughts, options, or solution summary.
  3. **STOP and wait for the user's explicit approval (YES / NO / feedback)** before taking any modifying action, executing code, or modifying files.
- Exception: Pure read-only requests (like "explain how X works" or direct questions) do not need code changes anyway, but for any work/changes, ALWAYS propose your thoughts first and wait for approval.
